# Ozon — инфографика товаров: OneLite Gold (WOODSTOCK)

Проект инфографики для карточек Ozon. Постоянное хранилище — папка
**«Ozon — инфографика товаров»** в Google Drive; этот репозиторий — рабочая среда
(скрипты вёрстки, шрифты, ассеты), из которой собираются финальные файлы.

## Актуальный результат: v02 (на реальных фото товара)
Серия `..._v02.png`: обложка, применение, зернистость, 8 отверстий, крупный план,
размер и упаковка, финал. Комплекты: ZIP, PDF-предпросмотр, контакт-лист.
Входные фото товара — `_MG_*` (Google Drive → `Входные_материалы`).
Проверено по фото: рабочая сторона светло-жёлтая, обратная — велкро-подложка
с печатью «P100», отверстий ровно 8, упаковка ONELITE. Количество в упаковке
не подтверждено и не указано.

## Структура репозитория
```
assets/
  fonts/     Manrope (instances 400–800, кириллица) + вариативный исходник
  logo/      woodstock_logo_light.png — официальный логотип под тёмный фон
  scenes/    иллюстративные сцены (генерированные), подписаны как иллюстрации
src/
  ds.py            дизайн-система: палитра, типографика, фон, примитивы
  ui2.py           стеклянные панели, строка характеристик, шапка с логотипом
  prep_assets.py   вырезки фото товара и крупные планы (повторяемо)
  diск.py / disc.py  рендер схемы диска (v01, число отверстий — параметр)
  slides.py        композиции v01 (схемы)
  slides_v2.py     композиции v02 (реальные фото)
  build.py         сборка v01: PNG + ZIP + PDF + контакт-лист
  build_v2.py      сборка v02
stage/       тексты для Drive: style_profile, product_brief, storyboard_copy, README
final/       собранная серия (v01)
```

## Пересборка серии
```bash
pip install pillow numpy
cd src && python3 prep_assets.py   # подготовить фото товара
cd src && python3 build_v2.py     # v02 -> ../final_v02
cd src && python3 build.py        # v01 -> ../final
```

## Важно (достоверность и правила)
- В v02 диск и упаковка — **реальные фотографии товара**; иллюстрацией остаётся только
  сцена шлифования на слайде 02 (помечена на слайде).
- Из референсов FILM GREEN не переносятся числовые обещания и свойства чужого SKU
  («до 3 раз дольше», «100 % водостойкость», «до 12 000 об/мин» и т. п.).
- Количество дисков в упаковке не подтверждено и на слайдах не указано.
- В линейке OneLite Gold есть другие значения зернистости — отражено в текстах.
- Цвет товара фирменной палитрой не подменяется: графит на слайдах — это оформление,
  реальный вид товара показывают фото/рендеры.
- Логотип WOODSTOCK используется из официального файла, без перерисовки.
