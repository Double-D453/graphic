# Референсы — WOODSTOCK / шлифовальные диски

Папка создана под референсы карточек этой категории. На момент v01 материалы не передавались.

Что сюда положить:
- скриншоты/файлы карточек-референсов (в т.ч. серия Film Green) — с них снимаем композицию,
  но не характеристики и не обещания;
- примеры оформления бренда для категории абразивов.

Формат имени: `Ref_<бренд>_<категория>_<что показывает>.<ext>` — исходные имена сохраняются.
