# Стиль-профиль: WOODSTOCK — шлифовальные диски (абразивы)

Статус: **черновик v1**, зафиксирован для категории «шлифовальные диски / абразивы».
Не переносить на другие категории WOODSTOCK без отдельного согласования.

## Источники
- Логотип: официальный файл `Woodstock_logo_White-Yellow-Black.tif` (папка бренда «ЛОГО»).
  Использована конвертированная копия под тёмный фон (`assets/logo/woodstock_logo_light.png`).
  Оригинал не перерисовывался и не изменялся.
- Фирменный цвет: золото **#F7B837**, графит/насыщенный тёмный **#0C1112**
  (снято с векторного логотипа; PDF «фирменные_цвета_вудсток» не содержит текстового слоя,
  поэтому палитра подтверждена только по логотипу).
- Референсы карточек пользователя (в т.ч. серия Film Green) на момент v01 **не передавались**.
  Композиция собрана на фирменной паре «золото + графит». Перед следующей версией желательно
  приложить референсы — логику композиции абразивов возьмём из них.

## Формат серии
- 1792 × 2400 px, вертикаль, sRGB. Рабочий ориентир (не официальное требование Ozon).
- Поля: 120 px по бокам, верхняя плашка-бренд на 118 px, футер на 2268 px.

## Типографика
- Гарнитура: **Manrope** (200–800, кириллица есть). Файлы: `assets/fonts/`.
- Надзаголовок: 32 px, вес 800, трекинг +3.6, золото, ВЕРХНИЙ РЕГИСТР.
- H1: 104 px, вес 800, белый, интерлиньяж 1.06.
- Подзаголовок: 44 px, вес 500, серый.
- Текст: 34–38 px, вес 500, серый, интерлиньяж 1.3.
- Крупные параметры: 54–140 px, вес 800, золото.
- Футер: 28 px, вес 500, тёмно-серый.

## Композиция и приёмы
- Один смысл на слайд, крупный заголовок в верхней трети, акцентный визуал в середине.
- Чипы параметров (P100 / Ø 125 мм / 8 отверстий) — скругление 18, золотая рамка.
- Нумерованные круглые бейджи для шагов и чек-листов.
- Панели с рамкой, тонкие разделители, выноски линиями с точкой.
- Нумерация «01 / 07» в правом верхнем углу, футер — ключевые параметры.
- Фон: графитовый градиент, тёплое свечение, зерно, виньетка.

- Схема товара помечается как схема, иллюстрация процесса — как иллюстрация.
- Инженерные данные (число отверстий, диаметр, форма отверстий) не додумываются.
- Никаких скидок, рейтингов, сертификатов, гарантий и сравнений без оснований.
