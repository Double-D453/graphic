# Product brief — OneLite Gold, Ø 125 мм, P100, 8 отверстий (v02)

## Подтверждено заданием
| Параметр | Значение |
|---|---|
| Бренд | WOODSTOCK (брендовый контекст), линейка ONELITE / OneLite Gold |
| Тип | шлифовальный диск (абразив) |
| Диаметр | 125 мм |
| Зернистость | P100 |
| Отверстия | 8 |
| В линейке | есть другие значения зернистости |

## Подтверждено фотографиями товара (загружены пользователем)
- Рабочая сторона диска — **светло-жёлтая** (зерно тёплого оттенка).
- Обратная сторона — **ворсистая (велкро) подложка** светло-серого цвета
  с многократно напечатанной маркировкой «P100».
- **На фотографии ровно 8 отверстий**, расположены по кругу (проверено автоматическим
  подсчётом светлых круглых зон на вырезке — 8).
- Отверстия сквозные, белые (видна подложка/просвет).
- Упаковка — чёрная картонная коробка с жёлтым логотипом ONELITE и надписью
  «SANDING DISC» / «PROFESSIONAL ABRASIVES».
- В комплекте съёмных данных нет: число дисков в упаковке на фото **не читается**.

## Не подтверждено — на слайдах НЕ указано
- Количество дисков в упаковке.
- Материал абразива (оксид алюминия и т. п.), тип основы, максимальные обороты,
  водостойкость, ресурс, гарантия, сертификаты, страна производства.
- Совместимость с конкретными моделями шлифмашинок.

## Допущения v02
1. Название линейки на слайдах — «OneLite Gold» (как в задании), рядом логотип WOODSTOCK;
   на фотографиях упаковки видна надпись ONELITE. Если нужно единое написание — поправлю.
2. Крепление описано как «ворсистая (велкро) подложка» — это видно на фото обратной
   стороны; формулировка осторожная, без названий систем.
3. Сцена шлифования (слайд 02) — иллюстрация, помечена на слайде.
4. Отверстия описаны как путь отвода пыли при работе «в паре» с перфорацией подошвы —
   общее назначение, без цифр и обещаний.
